# Передача дельт по платежам между системами

## 👤 **Kirill**

что значит передать "дельты" по платежам из одной банковкской системы в другую

---

## 🤖 **DeepSeek**

В банковском контексте **"дельты по платежам"** обычно означают **разницы** или **расхождения** между ожидаемыми и фактическими платежами, остатками или другими финансовыми показателями при передаче данных из одной системы в другую.  

### **Что может означать "передать дельты по платежам"?**  
1. **Корректировка расхождений**  
   - Если две банковские системы (например, старая и новая, или внутренняя и внешняя) имеют разные данные по платежам, то "дельты" — это список операций, которые нужно синхронизировать.  
   - Например: в системе А есть платежи 1, 2, 3, а в системе Б — 1, 2. "Дельта" — это платеж 3, который нужно передать.  

2. **Передача изменений (инкрементальные обновления)**  
   - Вместо полного выгрузки всех платежей передаются только новые или измененные (**дельты** — разница с предыдущей выгрузкой).  
   - Это экономит время и ресурсы при синхронизации.  

3. **Расхождения в остатках или проводках**  
   - Если между системами есть разница в балансах, "дельты" могут означать корректирующие проводки для выравнивания.  

### **Примеры ситуаций**  
- **Миграция данных** (переход с одной системы на другую) → передаются только новые/измененные платежи.  
- **Сверка с контрагентами** (например, между банком и клиринговой системой) → отправляются дельты для устранения расхождений.  
- **Ежедневная синхронизация** между филиалами или подразделениями банка.
