## 🤖 **DeepSeek**

### Описание диаграммы последовательности  

**Название:** Взаимодействие участников при выполнении операции СБП (Системы быстрых платежей)  

**Участники:**  
- **B** (Бизнес-партнёр / Инициатор операции)  
- **A** (Сервис авторизации API)  
- **K** (Посредник / Координатор операций)  
- **N** (НСПК — Национальная система платежных карт)  

**Основные этапы взаимодействия:**  

1. **Авторизация API**  
   - B отправляет запрос на авторизацию в сервис A.  
   - A подтверждает авторизацию и возвращает ответ B.  

2. **Запрос подтверждения операции СБП**  
   - B отправляет запрос в K на подтверждение возможности выполнения операции.  
   - K перенаправляет запрос в N (D01).  
   - N возвращает ответ о возможности выполнения операции (D02).  

3. **Подтверждение выполнения операции (холдирование средств)**  
   - B подтверждает выполнение операции, отправляя запрос в K.  
   - K передаёт распоряжение в N на выполнение операции (D05).  
   - N подтверждает получение распоряжения (D06) и уведомляет K о статусе операции (D21).  
   - K подтверждает получение финального статуса (D22).  
   - K возвращает B подтверждение выполнения операции СБП.  

4. **Финализация операции**  
   - K отправляет B подтверждение выполнения операции с реквизитами.  

**Примечание:**  
- Сообщения формата **DXX** соответствуют стандартизированным протоколам взаимодействия между НСПК и участниками СБП.  
- Пунктирные стрелки (`-[#FAFAFA]-`) обозначают завершение активности участника.  

**Цель диаграммы:**  
Наглядно отобразить последовательность взаимодействия между участниками при выполнении операции через Систему быстрых платежей, включая авторизацию, подтверждение и исполнение транзакции.
