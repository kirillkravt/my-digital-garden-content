## 👤 **Kirill**

---

## 🤖 **DeepSeek**

Для быстрых анимаций прохождения токенов по бизнес-процессам (workflow, BPMN) есть несколько архитектурных подходов. Выбор зависит от того, где выполняется код (бэкенд, фронтенд, генерация видео) и насколько «живой» должен быть результат.

Вот верхнеуровневый обзор решений, разделенный по стекам и сценариям использования:

### 1. Web-фронтенд (Интерактивные панели, мониторинг)
Это самый частый сценарий. Анимация идет в браузере.

*   **HTML Canvas + JavaScript (Pixi.js, Fabric.js, Konva):**
    *   *Суть:* Вы сами рисуете диаграмму (ноды, ребра) на Canvas. Токен — это спрайт или кружок.
    *   *Механика:* Задаете массив точек (путь). В `requestAnimationFrame` обновляете позицию объекта в процентах от пути.
    *   *Плюсы:* Максимальная производительность, контроль над каждой анимацией.
*   **D3.js:**
    *   *Суть:* Библиотека для визуализации данных. Умеет считать графовые layout и анимировать переходы.
    *   *Механика:* Используйте `selection.transition().attrTween('d', pathTween)` для движения объектов вдоль path.
    *   *Плюсы:* Красиво, много примеров именно по графам/диаграммам.
*   **SVG + Anime.js / GreenSock (GSAP):**
    *   *Суть:* Диаграмма рисуется как SVG-элемент. Токен — отдельный круг. Анимируется его движение вдоль линии с помощью `MotionPathPlugin`.
    *   *Плюсы:* Очень плавно, просто реализовать, хорошо работает с BPMN-нотацией.

### 2. Серверный рендеринг (Генерация GIF/MP4/APNG)
Нужно, если анимацию нельзя посчитать на клиенте (отчеты, видео-инструкции, телеграм-боты).

*   **Manim (3Blue1Brown):**
    *   *Суть:* Питоновская библиотека для математических анимаций.
    *   *Механика:* Рисуем граф через `Graph` или кастомные `VGroup`. Токен — `Dot`. Двигаем по алгоритму: стерли с одного узла, нарисовал на другом.
    *   *Плюсы:* Потрясающее качество, легко управлять сценой.
*   **Remotion:**
    *   *Суть:* Написание видео на React.
    *   *Механика:* Описываем диаграмму как компонент. Токен — абсолютно позиционируемый div/circle. Перемещаем, меняя `top`/`left` или `transform` в зависимости от текущего кадра.
    *   *Плюсы:* Настоящее программирование, полный контроль, интеграция с React-экосистемой.
*   **FFmpeg + Скрипты:**
    *   *Суть:* Если диаграмма статична, а нужно показать просто «горящие» точки. Генерируем N кадров (PIL/OpenCV) и склеиваем в видео.

### 3. Интерактивные графы (Node-based)
Если нужно не просто посмотреть, а покликать, перетащить узлы.

*   **React Flow / Svelte Flow:**
    *   *Суть:* Библиотеки для построения нодовых редакторов.
    *   *Механика:* Есть кастомные ноды. Вы можете добавить поверх канваса плавающую иконку (токен) и перемещать её координаты относительно порта (handle).
    *   *Плюсы:* Из коробки работа с графами, зуминг, панорамирование. Минус — анимировать сложные траектории (не прямые) труднее.
*   **GoJS:**
    *   *Суть:* Платная, но мощная библиотека для диаграмм.
    *   *Механика:* Встроенная поддержка токенов, инструментов симуляции. Просто подкладываете данные, она сама рисует бегущие огоньки.

### 4. Специфические визуализации данных (Data Viz)
*   **Gephi Streaming / Sigma.js:** Если процессы похожи на социальный граф, а токен — это волна.

---

### Резюме (Что выбрать?)

1.  **Нужно быстро в вебе и бюджетно:** Берите **SVG + GreenSock (GSAP)**. GreenSock сам просчитывает кривизну линий, легко синхронизировать несколько токенов.
2.  **Нужно на Python (ML/Data Science):** **Manim** (сложнее) или **Pillow/OpenCV** (покадровая отрисовка простых линий).
3.  **Нужно встроить в React-дашборд:** **Remotion** (если ролик) или **React Flow + кастомная анимация на `requestAnimationFrame`** (если живой мониторинг).
4.  **Если диаграммы — это BPMN-строго:** Используйте **bpmn-js + токены**. У bpmn-js есть extension-механизмы, позволяющие поверх нарисованной схемы пускать объекты.

## Что выбрать для "токенов по диаграмме"?

### ✅ **GSAP — лучше, но с оговоркой:**
- **MotionPathPlugin** — это магия. Вы просто даете ему SVG-путь (линию связи между узлами), а он сам двигает кружок строго по кривой, с учетом изгибов, скорости, ориентации.
- Анимации шелковые, 60fps, тормозов нет.
- Плагин требует лицензии для крупного бизнеса, но для вас — скорее всего бесплатно.

**Пример кода:**
```javascript
gsap.to('.token', {
  motionPath: {
    path: '#edge1', // ID линии в SVG
    align: '#edge1',
    autoRotate: true,
    start: 0,
    end: 1
  },
  duration: 3,
  repeat: -1,
  ease: 'linear'
})
```

### ✅ **Anime.js — честно бесплатно, но:**
- **Нет встроенного MotionPath**. Придется либо писать свой велосипед (двигать объект вдоль кривой Безье с пересчетом координат), либо использовать библиотеку `anime-motion-path` (сторонняя, неофициальная).
- Проще говоря: **на GSAP задача решается в 3 строки, на Anime.js — в 30+ строк с математикой**.

### 🔥 MVP-код:


## 🎯 Уровень 2: Кастомный парсер (полный контроль)

Если bpmn-js тяжелый, парсим XML руками и строим свои пути.

```javascript
async function parseBPMN(xmlString) {
    const parser = new DOMParser();
    const xml = parser.parseFromString(xmlString, 'text/xml');
    
    // 1. Достаем координаты из BPMNDiagram
    const shapes = xml.querySelectorAll('bpmndi\\:BPMNShape, BPMNShape');
    const edges = xml.querySelectorAll('bpmndi\\:BPMNEdge, BPMNEdge');
    
    const nodes = {};
    const flows = [];
    
    // Парсим узлы (круги, прямоугольники)
    shapes.forEach(shape => {
        const id = shape.getAttribute('bpmnElement');
        const bounds = shape.querySelector('dc\\:Bounds, Bounds');
        if (bounds) {
            nodes[id] = {
                x: parseFloat(bounds.getAttribute('x')),
                y: parseFloat(bounds.getAttribute('y')),
                width: parseFloat(bounds.getAttribute('width')),
                height: parseFloat(bounds.getAttribute('height'))
            };
        }
    });
    
    // Парсим связи и строим пути
    edges.forEach(edge => {
        const id = edge.getAttribute('bpmnElement');
        const waypoints = edge.querySelectorAll('di\\:waypoint, waypoint');
        
        let d = '';
        waypoints.forEach((point, i) => {
            const x = parseFloat(point.getAttribute('x'));
            const y = parseFloat(point.getAttribute('y'));
            if (i === 0) d += `M${x},${y}`;
            else d += ` L${x},${y}`;
        });
        
        flows.push({ id, path: d });
    });
    
    return { nodes, flows };
}

// Использование:
const { flows } = await parseBPMN(bpmnXML);
flows.forEach(flow => {
    // Рисуем путь в SVG
    const path = document.createElementNS('http://www.w3.org/2000/svg', 'path');
    path.setAttribute('d', flow.path);
    path.setAttribute('id', flow.id);
    svg.appendChild(path);
});
```

```javascript
function calculateConnectionPoints(sourceNode, targetNode, waypoints = []) {
    // Если есть явные waypoints из BPMNDI — берем их
    if (waypoints.length > 0) return waypoints;
    
    // Иначе вычисляем ближайшие точки на границах
    const sourceCenter = {
        x: sourceNode.x + sourceNode.width/2,
        y: sourceNode.y + sourceNode.height/2
    };
    const targetCenter = {
        x: targetNode.x + targetNode.width/2,
        y: targetNode.y + targetNode.height/2
    };

    const start = getIntersectionPoint(sourceNode, sourceCenter, targetCenter);

}

function buildSmoothPath(points) {
    if (points.length === 2) {
```

```javascript
class BPMNTokenAnimator {
    constructor(containerId) {
        this.viewer = new BpmnJS({ container: containerId });
        this.tokenLayer = null;
        this.tokens = [];
    }
    
    async loadDiagram(bpmnXML) {
        await this.viewer.importXML(bpmnXML);
        
        // Создаем слой для токенов
        const svg = document.querySelector(`${containerId} svg`);
        this.tokenLayer = document.createElementNS('http://www.w3.org/2000/svg', 'g');
        this.tokenLayer.setAttribute('id', 'token-layer');
        svg.appendChild(this.tokenLayer);
        
        // Индексируем все потоки
        this.flows = this.extractFlows();
    }
    
    extractFlows() {
        const elementRegistry = this.viewer.get('elementRegistry');
        const flows = {};
        
        elementRegistry.filter(el => el.type === 'bpmn:SequenceFlow').forEach(flow => {
            const gfx = elementRegistry.getGraphics(flow.id);
            const path = gfx.querySelector('path');
            if (path) {
                flows[flow.id] = {
                    path: path.getAttribute('d'),
                    source: flow.source,
                    target: flow.target
                };
            }
        });
        
        return flows;
    }
    
    createToken(startFlowId, color = '#ff4757') {
        const flow = this.flows[startFlowId];
        if (!flow) return;
        
        // Берем первую точку пути
        const firstPoint = this.getPathStartPoint(flow.path);
        
        const token = document.createElementNS('http://www.w3.org/2000/svg', 'circle');
        token.setAttribute('cx', firstPoint.x);
        token.setAttribute('cy', firstPoint.y);
        token.setAttribute('r', '8');
        token.setAttribute('fill', color);
        
        this.tokenLayer.appendChild(token);
        return token;
    }
    
    runToken(token, flowId) {
        gsap.to(token, {
            duration: 2,
            motionPath: {
                path: flowId,
                align: flowId,
                start: 0,
                end: 1
            },
            ease: 'linear',
            onComplete: () => {
                // Переходим к следующему потоку
                const flow = this.flows[flowId];
                const outgoingFlows = this.getOutgoingFlows(flow.target.id);
                if (outgoingFlows.length > 0) {
                    this.runToken(token, outgoingFlows[0].id);
                }
            }
        });
    }
    
    getOutgoingFlows(nodeId) {
        return Object.values(this.flows).filter(f => f.source.id === nodeId);
    }
}

// ИСПОЛЬЗОВАНИЕ:
const animator = new BPMNTokenAnimator('#canvas');

const token = animator.createToken('Flow_1');
animator.runToken(token, 'Flow_1');
```

```html
        async function loadBPMNDiagram(xml) {
            try {
                await viewer.importXML(xml);
                
                // Получаем реестр элементов
                store.elementRegistry = viewer.get('elementRegistry');
                
                // Очищаем слой токенов
                store.tokenLayer.innerHTML = '';
                store.tokens.clear();
                store.nextTokenId = 1;
                
                // Парсим все потоки
                parseAllFlows();
                
                // Строим все возможные маршруты
                buildAllRoutes();
                
                // Обновляем статистику
                updateStats();
                
                document.getElementById('status').innerHTML = '✅ Диаграмма загружена';
                
                // Автомасштабирование

                canvas.zoom('fit-viewport');
                
            } catch (err) {

            }

        // === 4. ПАРСИНГ ВСЕХ ПОТОКОВ ===
        function parseAllFlows() {
            store.flows = {};
            
            // Находим все sequenceFlow
            const flowElements = store.elementRegistry.filter(el => 
                el.type === 'bpmn:SequenceFlow'
            );
            
            flowElements.forEach(flow => {
                if (flow.di && flow.di.waypoint) {
                    let d = '';
                    flow.di.waypoint.forEach((wp, i) => {
                        const x = Math.round(wp.x);
                        const y = Math.round(wp.y);
                        d += i === 0 ? `M${x},${y}` : ` L${x},${y}`;
                    });
                    
                    // Создаем path в слое токенов
                    const path = document.createElementNS('http://www.w3.org/2000/svg', 'path');
                    path.id = `path_${flow.id}`;
                    path.setAttribute('d', d);
                    path.setAttribute('fill', 'none');
                    path.setAttribute('stroke', 'none');
                    store.tokenLayer.appendChild(path);
                    
                    store.flows[flow.id] = {
                        id: flow.id,
                        path: path,
                        source: flow.source?.id,
                        target: flow.target?.id,
                        d: d
                    };
                }
            });
            
            document.getElementById('flowCount').innerHTML = Object.keys(store.flows).length;
            console.log('✅ Найдено потоков:', Object.keys(store.flows).length);
        }

        // === 5. ПОИСК ВСЕХ СТАРТОВ И МАРШРУТОВ ===
        function findAllStartEvents() {
            return store.elementRegistry.filter(el => 
                el.type === 'bpmn:StartEvent'
            );
        }

        function findAllEndEvents() {
            return store.elementRegistry.filter(el => 
                el.type === 'bpmn:EndEvent'
            );
        }

        // === 6. ПОСТРОЕНИЕ ВСЕХ МАРШРУТОВ (BFS) ===
        function buildAllRoutes() {
            store.routes = [];
            
            const startEvents = findAllStartEvents();
            const endEvents = findAllEndEvents().map(e => e.id);
            
            startEvents.forEach(start => {
                // BFS от старта до каждого энда
                const queue = [{
                    nodeId: start.id,
                    path: [],
                    visited: new Set([start.id])
                }];
                
                while (queue.length > 0) {
                    const current = queue.shift();
                    
                    // Проверяем, достигли ли конца
                    if (endEvents.includes(current.nodeId)) {
                        store.routes.push({
                            start: start.id,
                            end: current.nodeId,
                            flows: [...current.path]
                        });
                        continue;
                    }
                    
                    // Ищем исходящие потоки
                    const outgoing = Object.values(store.flows).filter(f => 
                        f.source === current.nodeId
                    );
                    
                    outgoing.forEach(flow => {
                        if (!current.visited.has(flow.target)) {
                            queue.push({
                                nodeId: flow.target,
                                path: [...current.path, flow.id],
                                visited: new Set([...current.visited, flow.target])
                            });
                        }
                    });
                }
            });
            
            document.getElementById('routeCount').innerHTML = store.routes.length;
            console.log('✅ Найдено маршрутов:', store.routes.length);
        }

        // === 7. ДОБАВЛЕНИЕ НОВОГО ТОКЕНА ===
        function addToken(routeIndex = 0, color = null) {
            if (store.routes.length === 0) {
                alert('Нет маршрутов! Загрузите диаграмму.');
                return;
            }
            
            // Выбираем маршрут
            routeIndex = routeIndex % store.routes.length;
            const route = store.routes[routeIndex];
            
            if (route.flows.length === 0) return;
            
            // Получаем первый поток
            const firstFlowId = route.flows[0];
            const firstFlow = store.flows[firstFlowId];
            
            if (!firstFlow) return;
            
            // Получаем стартовую точку
            const startPoint = getPathStartPoint(firstFlow.d);
            
            // Генерируем цвет
            const colors = ['#ff4444', '#44ff44', '#4444ff', '#ff44ff', '#ffaa44', '#44ffaa'];
            const tokenColor = color || colors[store.tokens.size % colors.length];
            
            // Создаем токен
            const tokenId = `token_${store.nextTokenId++}`;
            const token = document.createElementNS('http://www.w3.org/2000/svg', 'circle');
            token.id = tokenId;
            token.setAttribute('cx', startPoint.x);
            token.setAttribute('cy', startPoint.y);
            token.setAttribute('r', '10');
            token.setAttribute('fill', tokenColor);
            token.setAttribute('stroke', 'white');
            token.setAttribute('stroke-width', '2');
            token.setAttribute('filter', `drop-shadow(0 0 6px ${tokenColor})`);
            
            store.tokenLayer.appendChild(token);
            
            // Сохраняем токен
            store.tokens.set(tokenId, {
                id: tokenId,
                element: token,
                route: route,
                currentFlowIndex: 0,
                timeline: null,
                color: tokenColor,
                loop: false
            });
            
            updateStats();
            return tokenId;
        }

        // === 8. ЗАПУСК ТОКЕНА ===
        function startToken(tokenId) {
            const tokenData = store.tokens.get(tokenId);
            if (!tokenData) return;
            
            // Останавливаем старую анимацию
            if (tokenData.timeline) tokenData.timeline.kill();
            
            const route = tokenData.route;
            tokenData.currentFlowIndex = 0;
            
            // Создаем таймлайн
            const timeline = gsap.timeline({
                onComplete: () => {
                    // Зацикливаем если нужно
                    if (tokenData.loop) {
                        startToken(tokenId);
                    }
                }
            });
            
            // Добавляем каждый шаг маршрута
            route.flows.forEach((flowId, index) => {
                const flow = store.flows[flowId];
                if (flow) {
                    timeline.to(tokenData.element, {
                        duration: 2,
                        motionPath: {
                            path: flow.path,
                            align: flow.path,
                            start: 0,
                            end: 1
                        },
                        ease: 'linear'
                    });
                }
            });
            
            tokenData.timeline = timeline;
        }

        // === 9. ЗАПУСК ВСЕХ ТОКЕНОВ ===
        function startAllTokens() {
            store.tokens.forEach((_, tokenId) => {
                startToken(tokenId);
            });
            document.getElementById('status').innerHTML = '▶ Все токены запущены';
        }

        // === 10. ОСТАНОВКА ВСЕХ ===
        function stopAllTokens() {
            store.tokens.forEach(tokenData => {
                if (tokenData.timeline) tokenData.timeline.kill();
            });
            document.getElementById('status').innerHTML = '⏹ Все токены остановлены';
        }

        // === 11. СБРОС ВСЕХ ===
        function resetAllTokens() {
            stopAllTokens();
            
            store.tokens.forEach(tokenData => {
                const route = tokenData.route;
                if (route && route.flows.length > 0) {
                    const firstFlow = store.flows[route.flows[0]];
                    if (firstFlow) {
                        const startPoint = getPathStartPoint(firstFlow.d);
                        gsap.set(tokenData.element, {
                            attr: { cx: startPoint.x, cy: startPoint.y }
                        });
                    }
                }
            });
            
            document.getElementById('status').innerHTML = '↺ Токены сброшены';
        }

        // === 12. ПОЛУЧЕНИЕ СТАРТОВОЙ ТОЧКИ ===
        function getPathStartPoint(d) {
            const match = d.match(/M(\d+),(\d+)/);
            if (match) {
                return { x: parseInt(match[1]), y: parseInt(match[2]) };
            }
            return { x: 0, y: 0 };
        }

        // === 13. ОБНОВЛЕНИЕ СТАТИСТИКИ ===
        function updateStats() {
            document.getElementById('tokenCount').innerHTML = store.tokens.size;
        }

        // === 14. ИНИЦИАЛИЗАЦИЯ КНОПОК ===
        window.onload = () => {
            // Добавление токена
            document.getElementById('addTokenBtn').addEventListener('click', () => {
                if (store.routes.length > 0) {
                    // Добавляем токен на каждый маршрут
                    for (let i = 0; i < store.routes.length; i++) {
                        addToken(i);
                    }
                }
            });
            
            document.getElementById('startAllBtn').addEventListener('click', startAllTokens);
            document.getElementById('stopAllBtn').addEventListener('click', stopAllTokens);
            document.getElementById('resetAllBtn').addEventListener('click', resetAllTokens);
            
            // Загружаем демо-схему при старте
            setTimeout(() => {
                document.getElementById('loadDemoBtn').click();
            }, 100);
        };
```

```html
            flows: new Map(),
            nodes: new Map(),

        // === УТИЛИТЫ ДЛЯ ТОЧЕК ===
        function getNodeConnectionPoint(nodeId, isSource = true) {
            const node = store.nodes.get(nodeId);
            if (!node) return null;
            
            // Берем точку на границе, а не в центре
            if (isSource) {
                // Правая сторона для исходящих
                return {
                    x: node.x + node.width,
                    y: node.y + node.height / 2
                };
            } else {
                // Левая сторона для входящих
                return {
                    x: node.x,
                    y: node.y + node.height / 2
                };
            }
        }

        function calculateOptimalPath(sourceId, targetId, waypoints = []) {
            // Если есть waypoints из диаграммы - используем их
            if (waypoints && waypoints.length > 0) {
                let d = '';
                waypoints.forEach((wp, i) => {
                    const x = Math.round(wp.x);
                    const y = Math.round(wp.y);
                    d += i === 0 ? `M${x},${y}` : ` L${x},${y}`;
                });
                return d;
            }
            
            // Иначе строим оптимальный путь
            const source = store.nodes.get(sourceId);
            const target = store.nodes.get(targetId);
            
            if (!source || !target) return '';
            
            const startX = source.x + source.width;
            const startY = source.y + source.height / 2;
            const endX = target.x;
            const endY = target.y + target.height / 2;
            
            // Прямая линия или с изгибом?
            if (Math.abs(startY - endY) < 50) {
                return `M${startX},${startY} L${endX},${endY}`;
            } else {
                // Добавляем промежуточную точку для красивого изгиба
                const midX = (startX + endX) / 2;
                return `M${startX},${startY} L${midX},${startY} L${midX},${endY} L${endX},${endY}`;
            }
        }

        // === ПАРСИНГ BPMN ===
        async function parseBPMN(xml) {
            try {
                await viewer.importXML(xml);
                
                store.elementRegistry = viewer.get('elementRegistry');
                store.tokenLayer.innerHTML = '';
                store.flows.clear();
                store.nodes.clear();
                
                // Парсим все ноды (шейпы)
                const shapes = store.elementRegistry.filter(el => 
                    el.type.includes('bpmn:') && el.di && el.di.bounds
                );
                
                shapes.forEach(shape => {
                    if (shape.di.bounds) {
                        store.nodes.set(shape.id, {
                            id: shape.id,
                            type: shape.type,
                            x: Math.round(shape.di.bounds.x),
                            y: Math.round(shape.di.bounds.y),
                            width: Math.round(shape.di.bounds.width),
                            height: Math.round(shape.di.bounds.height)
                        });
                        
                        // Запоминаем старты и энды
                        if (shape.type === 'bpmn:StartEvent') {
                            store.startEvents.push(shape.id);
                        }
                        if (shape.type === 'bpmn:EndEvent') {
                            store.endEvents.push(shape.id);
                        }
                    }
                });
                
                // Парсим все потоки
                const flows = store.elementRegistry.filter(el => 
                    el.type === 'bpmn:SequenceFlow'
                );
                
                flows.forEach(flow => {
                    let waypoints = [];
                    if (flow.di && flow.di.waypoint) {
                        waypoints = flow.di.waypoint;
                    }
                    
                    // Оптимальный путь
                    const d = calculateOptimalPath(
                        flow.source?.id, 
                        flow.target?.id, 
                        waypoints
                    );
                    
                    if (d) {
                        const path = document.createElementNS('http://www.w3.org/2000/svg', 'path');
                        path.id = `path_${flow.id}`;
                        path.setAttribute('d', d);
                        path.setAttribute('fill', 'none');
                        path.setAttribute('stroke', 'none');
                        store.tokenLayer.appendChild(path);
                        
                        store.flows.set(flow.id, {
                            id: flow.id,
                            path: path,
                            source: flow.source?.id,
                            target: flow.target?.id,
                            d: d
                        });
                    }
                });
                
                // Строим маршруты
                buildRoutes();
                updateStats();
                
                document.getElementById('status').innerHTML = '✅ Загружено';
                document.getElementById('flowCount').innerHTML = store.flows.size;
                document.getElementById('startCount').innerHTML = store.startEvents.length;
                document.getElementById('endCount').innerHTML = store.endEvents.length;
                
                const canvas = viewer.get('canvas');
                canvas.zoom('fit-viewport');
                
            } catch (err) {
                console.error(err);
                showError('Ошибка парсинга BPMN: ' + err.message);
            }
        }

        // === ПАРСИНГ DRAW.IO ===
        async function parseDrawio(xml) {
            try {
                // Парсим XML
                const parser = new DOMParser();
                const doc = parser.parseFromString(xml, 'text/xml');
                
                // Ищем корневой элемент диаграммы
                const root = doc.documentElement;
                let diagramXml = '';
                
                if (root.tagName === 'mxGraphModel') {
                    // Это чистый draw.io
                    diagramXml = convertDrawioToBPMN(root);
                } else {
                    // Ищем внутри
                    const mxGraph = root.querySelector('mxGraphModel');
                    if (mxGraph) {
                        diagramXml = convertDrawioToBPMN(mxGraph);
                    }
                }
                
                if (diagramXml) {
                    await parseBPMN(diagramXml);
                } else {
                    throw new Error('Не удалось найти диаграмму в файле');
                }
                
            } catch (err) {
                console.error(err);
                showError('Ошибка парсинга draw.io: ' + err.message);
            }
        }

        // === КОНВЕРТАЦИЯ DRAW.IO В BPMN ===
        function convertDrawioToBPMN(mxGraph) {
            // Создаем базовую BPMN-структуру
            const cells = mxGraph.querySelectorAll('root > mxCell');
            
            // Генерируем ID для процесса
            const processId = 'Process_' + Date.now();
            
            let bpmn = `<?xml version="1.0" encoding="UTF-8"?>
            <bpmn:definitions xmlns:bpmn="http://www.omg.org/spec/BPMN/20100524/MODEL"
                             xmlns:bpmndi="http://www.omg.org/spec/BPMN/20100524/DI"
                             xmlns:dc="http://www.omg.org/spec/DD/20100524/DC"
                             xmlns:di="http://www.omg.org/spec/DD/20100524/DI"
                             targetNamespace="http://bpmn.io/schema/bpmn">
                
                <bpmn:process id="${processId}" isExecutable="true">`;
            
            // Добавляем элементы
            const elements = new Map();
            
            cells.forEach(cell => {
                const id = cell.getAttribute('id');
                const style = cell.getAttribute('style') || '';
                const value = cell.getAttribute('value') || '';
                const parent = cell.getAttribute('parent');
                const vertex = cell.getAttribute('vertex');
                const edge = cell.getAttribute('edge');
                const geometry = cell.querySelector('mxGeometry');
                
                if (vertex === '1' && geometry && parent !== '1') {
                    // Это нода
                    const x = parseFloat(geometry.getAttribute('x')) || 0;
                    const y = parseFloat(geometry.getAttribute('y')) || 0;
                    const width = parseFloat(geometry.getAttribute('width')) || 100;
                    const height = parseFloat(geometry.getAttribute('height')) || 80;
                    
                    let type = 'bpmn:Task';
                    if (style.includes('ellipse') || style.includes('circle')) {
                        type = value.includes('Start') ? 'bpmn:StartEvent' : 'bpmn:EndEvent';
                    } else if (style.includes('rhombus')) {
                        type = 'bpmn:ExclusiveGateway';
                    }
                    
                    const bpmnId = `${type.split(':')[1]}_${id}`;
                    elements.set(id, { bpmnId, type, x, y, width, height });
                    
                    bpmn += `<bpmn:${type.split(':')[1]} id="${bpmnId}" name="${value}" />`;
                }
            });
            
            // Добавляем потоки
            cells.forEach(cell => {
                const edge = cell.getAttribute('edge');
                if (edge === '1') {
                    const source = cell.getAttribute('source');
                    const target = cell.getAttribute('target');
                    
                    if (source && target && elements.has(source) && elements.has(target)) {
                        const flowId = `Flow_${cell.getAttribute('id')}`;
                        bpmn += `<bpmn:sequenceFlow id="${flowId}" 
                                sourceRef="${elements.get(source).bpmnId}" 
                                targetRef="${elements.get(target).bpmnId}" />`;
                    }
                }
            });
            
            bpmn += `</bpmn:process>
                
                <bpmndi:BPMNDiagram id="BPMNDiagram_1">
                    <bpmndi:BPMNPlane id="BPMNPlane_1" bpmnElement="${processId}">`;
            
            // Добавляем DI для шейпов
            elements.forEach((el, id) => {
                bpmn += `<bpmndi:BPMNShape id="${el.bpmnId}_di" bpmnElement="${el.bpmnId}">
                            <dc:Bounds x="${el.x}" y="${el.y}" width="${el.width}" height="${el.height}" />
                        </bpmndi:BPMNShape>`;
            });
            
            // Добавляем DI для эджей
            cells.forEach(cell => {
                const edge = cell.getAttribute('edge');
                if (edge === '1') {
                    const source = cell.getAttribute('source');
                    const target = cell.getAttribute('target');
                    const geometry = cell.querySelector('mxGeometry');
                    
                    if (source && target && elements.has(source) && elements.has(target)) {
                        const flowId = `Flow_${cell.getAttribute('id')}`;
                        bpmn += `<bpmndi:BPMNEdge id="${flowId}_di" bpmnElement="${flowId}">`;
                        
                        // Добавляем waypoints
                        if (geometry) {
                            const points = geometry.querySelectorAll('Array > mxPoint');
                            if (points.length > 0) {
                                points.forEach(point => {
                                    const x = point.getAttribute('x');
                                    const y = point.getAttribute('y');
                                    bpmn += `<di:waypoint x="${x}" y="${y}" />`;
                                });
                            } else {
                                // Прямая линия от source к target
                                const sourceEl = elements.get(source);
                                const targetEl = elements.get(target);
                                bpmn += `<di:waypoint x="${sourceEl.x + sourceEl.width}" y="${sourceEl.y + sourceEl.height/2}" />
                                        <di:waypoint x="${targetEl.x}" y="${targetEl.y + targetEl.height/2}" />`;
                            }
                        }
                        
                        bpmn += `</bpmndi:BPMNEdge>`;
                    }
                }
            });
            
            bpmn += `</bpmndi:BPMNPlane>
                </bpmndi:BPMNDiagram>
            </bpmn:definitions>`;
            
            return bpmn;
        }

        // === ПОСТРОЕНИЕ МАРШРУТОВ (BFS) ===
        function buildRoutes() {
            store.routes = [];
            
            if (store.startEvents.length === 0) return;
            
            store.startEvents.forEach(startId => {
                const queue = [{
                    nodeId: startId,
                    path: [],
                    visited: new Set([startId])
                }];
                
                while (queue.length > 0) {
                    const current = queue.shift();
                    
                    if (store.endEvents.includes(current.nodeId)) {
                        store.routes.push({
                            start: startId,
                            end: current.nodeId,
                            flows: [...current.path]
                        });
                        continue;
                    }
                    
                    const outgoing = Array.from(store.flows.values())
                        .filter(f => f.source === current.nodeId);
                    
                    outgoing.forEach(flow => {
                        if (!current.visited.has(flow.target)) {
                            queue.push({
                                nodeId: flow.target,
                                path: [...current.path, flow.id],
                                visited: new Set([...current.visited, flow.target])
                            });
                        }
                    });
                }
            });
            
            document.getElementById('routeCount').innerHTML = store.routes.length;
        }

        // === ДОБАВЛЕНИЕ ТОКЕНА ===
        function addToken() {
            if (store.routes.length === 0) {
                showError('Нет маршрутов! Загрузите диаграмму.');
                return;
            }
            
            // Берем первый маршрут
            const route = store.routes[0];
            if (!route || route.flows.length === 0) return;
            
            const firstFlowId = route.flows[0];
            const firstFlow = store.flows.get(firstFlowId);
            
            if (!firstFlow) return;
            
            // Получаем ТОЧНУЮ стартовую точку
            const startPoint = getPathStartPoint(firstFlow.d);
            
            const colors = ['#ff4444', '#44ff44', '#4444ff', '#ff44ff', '#ffaa44', '#44ffaa'];
            const tokenColor = colors[store.tokens.size % colors.length];
            
            const tokenId = `token_${store.nextTokenId++}`;
            const token = document.createElementNS('http://www.w3.org/2000/svg', 'circle');
            token.id = tokenId;
            token.setAttribute('cx', startPoint.x);
            token.setAttribute('cy', startPoint.y);
            token.setAttribute('r', '10');
            token.setAttribute('fill', tokenColor);
            token.setAttribute('stroke', 'white');
            token.setAttribute('stroke-width', '2.5');
            token.setAttribute('filter', `drop-shadow(0 0 8px ${tokenColor})`);
            
            store.tokenLayer.appendChild(token);
            
            store.tokens.set(tokenId, {
                id: tokenId,
                element: token,
                route: route,
                currentFlowIndex: 0,
                timeline: null,
                color: tokenColor
            });
            
            updateStats();
        }

        // === ЗАПУСК ТОКЕНА ===
        function startToken(tokenId) {
            const tokenData = store.tokens.get(tokenId);
            if (!tokenData) return;
            
            if (tokenData.timeline) tokenData.timeline.kill();
            
            const route = tokenData.route;
            tokenData.currentFlowIndex = 0;
            
            const timeline = gsap.timeline({
                onComplete: () => {
                    // Автоматически сбрасываем на старт
                    resetToken(tokenId);
                }
            });
            
            route.flows.forEach((flowId, index) => {
                const flow = store.flows.get(flowId);
                if (flow) {
                    timeline.to(tokenData.element, {
                        duration: 2.5,
                        motionPath: {
                            path: flow.path,
                            align: flow.path,
                            start: 0,
                            end: 1,
                            autoRotate: true
                        },
                        ease: 'power1.inOut'
                    });
                }
            });
            
            tokenData.timeline = timeline;
        }

        // === СБРОС ТОКЕНА ===
        function resetToken(tokenId) {
            const tokenData = store.tokens.get(tokenId);
            if (!tokenData) return;
            
            if (tokenData.timeline) tokenData.timeline.kill();
            
            const firstFlowId = tokenData.route.flows[0];
            const firstFlow = store.flows.get(firstFlowId);
            
            if (firstFlow) {
                const startPoint = getPathStartPoint(firstFlow.d);
                gsap.set(tokenData.element, {
                    attr: { cx: startPoint.x, cy: startPoint.y }
                });
            }
        }

        // === ПОЛУЧЕНИЕ СТАРТОВОЙ ТОЧКИ ПУТИ ===
        function getPathStartPoint(d) {
            const match = d.match(/M(\d+),(\d+)/);
            if (match) {
                return { x: parseInt(match[1]), y: parseInt(match[2]) };
            }
            return { x: 0, y: 0 };
        }

        // === УПРАВЛЕНИЕ ТОКЕНАМИ ===
        function startAllTokens() {
            store.tokens.forEach((_, tokenId) => startToken(tokenId));
            document.getElementById('status').innerHTML = '▶ Токены запущены';
        }

        function stopAllTokens() {
            store.tokens.forEach(tokenData => {
                if (tokenData.timeline) tokenData.timeline.kill();
            });
            document.getElementById('status').innerHTML = '⏹ Токены остановлены';
        }

        function resetAllTokens() {
            stopAllTokens();
            store.tokens.forEach((_, tokenId) => resetToken(tokenId));
            document.getElementById('status').innerHTML = '↺ Токены сброшены';
        }

        // === ОБНОВЛЕНИЕ СТАТИСТИКИ ===
        function updateStats() {
            document.getElementById('tokenCount').innerHTML = store.tokens.size;
        }
```
