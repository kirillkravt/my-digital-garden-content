## 📋 КОНТРАКТ API

### РАЗРЕШЕННЫЕ МЕТОДЫ (ИСПОЛЬЗУЕМ):

```javascript
// 1. ИНИЦИАЛИЗАЦИЯ
window.initStrudel()           // Создает window.strudel
window.strudel.getAudioContext() // Получить AudioContext

// 2. ВОСПРОИЗВЕДЕНИЕ
window.strudel.evaluate(code)  // Единственный способ запуска паттернов
// Примеры:
strudel.evaluate('note("c4 e4 g4")')
strudel.evaluate('sound("bd hh")')

// 3. ОСТАНОВКА
const ctx = strudel.getAudioContext()
ctx.suspend()                  // ЕДИНСТВЕННЫЙ работающий способ остановки

// 4. УПРАВЛЕНИЕ СЕМПЛАМИ (когда починим)
strudel.loadSamples?('tr909')  // Предзагрузка банков
```

### ЗАПРЕЩЕННЫЕ МЕТОДЫ (НЕ РАБОТАЮТ / ЛОМАЮТ):

```javascript
// ❌ НЕ ИСПОЛЬЗОВАТЬ:

strudel.scheduler              // undefined

strudel.pause()                // Не существует
```

## 💾 КОД-ШАБЛОНЫ

### 1. МИНИМАЛЬНЫЙ РАБОЧИЙ КОМПОНЕНТ:

```typescript
// StrudelREPLNode.tsx - минимальная рабочая версия
export const StrudelREPLNode: React.FC<Props> = ({ nodeId, core }) => {
  const [isPlaying, setIsPlaying] = useState(false);
  const audioContextRef = useRef<AudioContext | null>(null);

  // 1. ИНИЦИАЛИЗАЦИЯ
  useEffect(() => {
    const init = async () => {
      if (!window.strudel) {
        await loadScript('https://unpkg.com/@strudel/web@latest');
        window.initStrudel?.();
      }
      
      audioContextRef.current = window.strudel?.getAudioContext();
      
      // Начинаем в suspended (требование autoplay policy)
      if (audioContextRef.current?.state === 'running') {
        await audioContextRef.current.suspend();
      }
    };
    
    init();
    
    // 2. ОЧИСТКА
    return () => {
      if (audioContextRef.current?.state !== 'closed') {
        audioContextRef.current?.close();
      }
    };
  }, []);

  // 3. PLAY
  const handlePlay = async () => {
    if (!audioContextRef.current || !window.strudel) return;
    
    await audioContextRef.current.resume();
    window.strudel.evaluate('note("c4 e4 g4")');
    setIsPlaying(true);
  };

  // 4. STOP (ЕДИНСТВЕННЫЙ РАБОЧИЙ СПОСОБ)
  const handleStop = async () => {
    if (!audioContextRef.current) return;
    
    await audioContextRef.current.suspend();
    setIsPlaying(false);
  };

  return (
    <div>
      <button onClick={handlePlay} disabled={isPlaying}>Play</button>
      <button onClick={handleStop} disabled={!isPlaying}>Stop</button>
    </div>
  );
};
```

```javascript
// ДИАГНОСТИКА (выполнить в консоли):
function checkAudioContexts() {
  const contexts = [];
  for (let key in window) {
    try {
      const obj = window[key];
      if (obj instanceof AudioContext || 
          (obj.constructor && obj.constructor.name === 'AudioContext')) {
        contexts.push({ key, state: obj.state });
      }
    } catch(e) {}
  }
  console.log('Найдено AudioContext:', contexts);
}
```

## 🆘 ЧАСТЫЕ ОШИБКИ И РЕШЕНИЯ

### ОШИБКА: `sound tr909_bd not found!`
**Решение:** Добавить `await strudel.loadSamples('tr909')` перед использованием

### ОШИБКА: `Cannot read properties of undefined (reading 'stop')`
**Причина:** Используете `strudel.hush()`
**Решение:** Использовать только `audioContext.suspend()`

### ОШИБКА: Вечная загрузка при сохранении файла
**Причина:** HMR конфликт
**Решение:** Добавить `import.meta.hot.decline()`

### ПРОБЛЕМА: Звук запускается сам при загрузке
**Причина:** AudioContext в состоянии 'running'
**Решение:** При инициализации вызывать `audioContext.suspend()`
