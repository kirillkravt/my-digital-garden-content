В Strudel генерация звука — это отдельный шаг, выполняемый **выходом (output)**. Библиотека `@strudel/core`, которую вы загрузили, занимается только логикой паттернов и их расписанием. Для воспроизведения звука через Web Audio API необходим отдельный пакет, например, `@strudel/webaudio`[citation:2][citation:5][citation:6].

Правильная инициализация выглядит сложнее, чем просто `run()`.
