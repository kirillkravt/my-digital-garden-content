# Реализация реального времени в TouchDesigner

---

## 🤖 **DeepSeek**

В реальном времени обработка в TouchDesigner организована через **нод-граф (поток данных)** и **цикл обработки кадров**. Вот ключевые механизмы:

## 1. **Поток данных (Data Flow)**
   - Каждый оператор (нода) обрабатывает данные при их изменении
   - Данные передаются по связям между операторами
   - TouchDesigner использует **ленивые вычисления** - данные вычисляются только когда запрашиваются

## 2. **Цикл обработки кадров**
```
1. Ввод (Input) → 2. Обновление (Cook) → 3. Вывод (Output) → 4. Ожидание (Wait)
```
   - **Cook** - основной этап, где каждый оператор "готовится" (обновляет свои данные)
   - Порядок обновления определяется топологической сортировкой графа

## 3. **Многоядерная обработка**
   - **COMP** операторы выполняются в отдельных потоках
   - Автоматическое распределение нагрузки по ядрам CPU
   - Использование GPU через **GLSL/Compute Shaders**

## 4. **Тайминги и приоритеты**
   ```python
   # Пример установки приоритета в Python
   op('my_node').par.executionmode = 'OnFrameEnd'  # или 'Immediate', 'OnFrameStart'
   ```
   - Режимы исполнения:
     - **Immediate** - сразу при изменении
     - **OnFrameStart/End** - в начале/конце кадра
     - **OnDemand** - только при запросе

## 5. **Оптимизации для реального времени**
   - **Кэширование** - операторы кэшируют результаты
   - **Пропуск кадров** при перегрузке (по желанию)
   - **Асинхронная загрузка** ресурсов
   - **Level of Detail (LOD)** - автоматическое упрощение при нагрузке

## 6. **Пример простой цепи обработки**
```
Webcam (VIDEO IN) → 
Color Correction TOP → 
Blur TOP → 
Feedback TOP (эффекты) → 
Out (вывод на проектор)
```
Все это работает в основном потоке 60 FPS без блокировок.

## 7. **Мониторинг производительности**
   - Performance Monitor (Alt+Shift+P)
   - Cook Times показывают время обработки каждого оператора
   - Профилировщик для поиска узких мест

## 8. **Работа с аудио**
   - Отдельный аудио граф с фиксированной частотой (обычно 48kHz)
   - Минимальная задержка через ASIO/WASAPI
   - Синхронизация с видео через таймкод

**Ключевое преимущество**: TouchDesigner минимизирует копирование данных между операторами, часто работая с ссылками на текстуры/буферы, что обеспечивает высокую производительность в реальном времени.

```python
class CreativeNode:
    def __init__(self):
        self.inputs = []      # Входные связи
        self.outputs = []     # Выходные связи
        self.cache = None     # Кэш результатов
        self.dirty = True     # Нужно пересчитать
        
    def cook(self):
        if not self.dirty and self.cache:
            return self.cache
        # Ленивые вычисления
        result = self.process()
        self.cache = result
        self.dirty = False
        return result
```

### **4. Реальный Time Management**
```python
class CreativeScheduler:
    def __init__(self):
        self.phases = {
            'input': [],      # Сбор данных
            'update': [],     # Основная логика
            'render': [],     # Визуализация
            'output': []      # Экспорт/стрим
        }
        self.frame_time = 1/60  # 60 FPS
        self.thread_pool = ThreadPoolExecutor()
    
    def process_frame(self):
        start = time.time()
        
        # Параллельная обработка независимых веток
        futures = []
        for node in self.get_parallel_nodes():
            future = self.thread_pool.submit(node.cook)
            futures.append(future)
        
        # Ожидание и сбор результатов
        results = [f.result() for f in futures]
        
        # Гарантированная частота кадров
        elapsed = time.time() - start
        sleep_time = max(0, self.frame_time - elapsed)
        time.sleep(sleep_time)
```
