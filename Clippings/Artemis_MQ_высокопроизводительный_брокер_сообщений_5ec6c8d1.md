# Artemis MQ: высокопроизводительный брокер сообщений

## 🤖 **DeepSeek**

**Artemis MQ** — это высокопроизводительный брокер сообщений, разработанный как преемник **Apache ActiveMQ**. Он входит в состав проекта **Apache ActiveMQ** (начиная с версии ActiveMQ 5.x) и представляет собой полностью переработанную версию брокера с улучшенной архитектурой.  

### 🔹 **Основные особенности Artemis MQ**:
- **Высокая производительность**:  
  - Использует **асинхронную модель ввода-вывода** (на основе Netty и Java NIO).  
  - Поддерживает **журналирование (journaling)** для быстрой записи сообщений.  
  - Оптимизирован для работы с большими нагрузками (миллионы сообщений в секунду).  

- **Поддержка протоколов**:  
  - **AMQP** (Advanced Message Queuing Protocol)  
  - **STOMP** (Simple Text Oriented Messaging Protocol)  
  - **MQTT** (для IoT-устройств)  
  - **OpenWire** (совместимость с ActiveMQ 5.x)  
  - **Core Protocol** (родной протокол Artemis)  

- **Кластеризация и отказоустойчивость**:  
  - Поддержка **репликации** (HA — High Availability).  
  - **Шардирование** (разделение нагрузки между узлами).  
  - **Автоматическое переподключение** клиентов при сбоях.  

- **Persistence (сохранение сообщений)**:  
  - **Журнал на основе файлов** (похоже на Kafka, но с гибкими настройками).  
  - Поддержка **PostgreSQL, JDBC, Kafka** в качестве хранилища (в Enterprise-версии).  

- **Интеграция с Jakarta EE / MicroProfile**:  
  - Полная поддержка **JMS 2.0** (Java Message Service).  
  - Совместимость с **Jakarta EE** и **MicroProfile Reactive Messaging**.  

- **Управление и мониторинг**:  
  - **REST API** для администрирования.  
  - **JMX** (Java Management Extensions).  
  - **Web Console** (веб-интерфейс для мониторинга очередей).  

### 🔹 **Чем отличается Artemis от ActiveMQ 5.x?**  
| Характеристика       | ActiveMQ 5.x | Artemis (ActiveMQ 6+) |  
|----------------------|-------------|----------------------|  
| **Архитектура**      | Монолитная  | Модульная, асинхронная |  
| **Производительность** | Средняя    | Очень высокая        |  
| **Протоколы**        | Много, но медленные | Оптимизированные |  
| **Persistence**      | KahaDB, JDBC | Журнал (Journal) + JDBC |  
| **Кластеризация**    | Есть, но сложная | Гибкая и масштабируемая |  

### 🔹 **Где используется?**  
- **Финансовые системы** (высокие нагрузки, низкие задержки).  
- **Телеком** (обработка событий в реальном времени).  
- **IoT** (поддержка MQTT).  
- **Микросервисы** (интеграция через AMQP/JMS).  

### 🔹 **Как запустить?**  
1. Скачать с [официального сайта Apache ActiveMQ Artemis](https://activemq.apache.org/components/artemis/).  
2. Создать брокер:  
   ```sh
   ./artemis create mybroker
   ```
3. Запустить:  
   ```sh
   ./mybroker/bin/artemis run
   ```
4. Веб-консоль доступна по умолчанию на `http://localhost:8161/console`.  

### **Вывод**  
Artemis MQ — это современный, быстрый и надежный брокер сообщений, который подходит для высоконагруженных систем. Если вам нужна альтернатива **RabbitMQ или Kafka**, но с поддержкой **JMS**, Artemis — отличный выбор. 🚀

На данный момент у меня нет информации о действующих промокодах **Яндекс Маркет** на сантехнику. Промокоды часто меняются, и лучший способ найти актуальные — проверить официальные источники:  

### 🔹 **Где искать промокоды на Яндекс Маркет?**  
1. **Официальный сайт/приложение Яндекс Маркет**  
   - В разделе **"Акции"** или **"Промокоды"**.  
   - В карточках товаров из категории **"Сантехника"** могут быть специальные предложения.  

2. **Кэшбэк-сервисы**  
   - **Letyshops**, **EpicBonus**, **Cashbacker** — иногда дают промокоды + возврат части суммы.  

3. **Телеграм-каналы и сайты с купонами**  
   - Например: **"Промокоды Яндекс Маркет"**, **"Халява Маркет"**, **"Dolyame.ru"**.  

4. **Банки-партнеры**  
   - Сбербанк, Тинькофф, Альфа-Банк иногда предлагают скидки через их приложения.  

### 🔹 **Как увеличить шансы на скидку?**  
✅ **Дождитесь распродаж** (Черная пятница, 11.11, 8 марта, Новый год).  
✅ **Проверьте раздел "Уценённые товары"** — иногда там есть сантехника со скидкой.  
✅ **Оформите подписку Яндекс Плюс** — даёт дополнительные бонусы.  

Если вам нужен промокод прямо сейчас, попробуйте ввести в корзине:  
- **MARKET10** (возможно, устарел, но иногда срабатывает).  
- **ЯНДЕКСПЛЮС** (для подписчиков).  

Лучше всего заглянуть в **официальный раздел акций** Яндекс Маркета или подписаться на рассылку. 🛁🚿
