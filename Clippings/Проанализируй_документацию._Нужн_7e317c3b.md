```typescript
interface AudioAdapter {

  disconnect(): void;
```

```typescript
// 1. Coexistence Layer
class HybridOrchestrator {
  private legacy: CoreOrchestrator;

  // Использует либо старый код, либо адаптеры
}

// 2. Migration Layer  
class MigrationManager {
  private migrationQueue: MigrationTask[];
  async migrateComponent(component: string): Promise<void>
}

// 3. Unified Layer
class UnifiedOrchestrator {

}
```

## 🎨 2. Node Canvas UX - Сравнение вариантов

Вот 3 варианта для "расширяемой ноды", где StrudelNode раскрывается в большую область:

### Вариант 1: Контекстный редактор (Node-RED стиль)
```
┌─────────────────────────────────────┐
│        Canvas с нодами              │
│                                     │
│  [Clock]═══[Strudel]═══[Filter]     │
│      │          │           │       │
│      └──────────┴───────────┘       │
│                                     │
└─────────────────────────────────────┘
    ↓ клик на Strudel ноду
┌─────────────────────────────────────┐
│  ┌─────────┐                        │
│  │ Clock   │     РЕДАКТОР КОДА      │
│  └─────────┘     (занимает 70%      │
│  [Filter]        экрана)            │
│                 ┌─────────────────┐ │
│                 | s("bd hh sd")   | │
│                 | .speed(2)       | │
│                 └─────────────────┘ │
└─────────────────────────────────────┘
```
**Плюсы:** Чисто, фокус на код, похоже на Node-RED  
**Минусы:** Нужно переключать контекст

### Вариант 2: Всплывающий редактор (Ableton Live стиль)
```
┌─────────────────────────────────────┐
│  [Clock] [Strudel] [Filter]         │
│                                     │
│                                     │
│        (остальные ноды мельче)      │
│                                     │
└─────────────────────────────────────┘
    ↓ двойной клик на Strudel
┌─────────────────────────────────────┐
│  МОДАЛЬНОЕ ОКНО поверх всего        │
│  ┌─────────────────────────────┐    │
│  │ STRUDEL EDITOR              │    │
│  │ s("bd hh sd cp").speed(2)   │    │
│  │   .room(0.5).size(0.8)      │    │
│  │                             │    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘
```
**Плюсы:** Полный фокус на редактировании  
**Минусы:** Перекрывает остальной интерфейс

### Вариант 3: Расширяемая панель (VS Code стиль)

```
┌───────┬─────────────────────────────┐
```
