## 🎯 **Ключевые технические открытия и решения**

### **Проблема:**
Исходный кастомный бандл Strudel не работал из-за:
1. Неполного набора зависимостей (только `@strudel/core`)
2. Неправильного порядка инициализации
3. Отсутствия регистрации звуковых банков

### **Решение:**
1. **Полный набор модулей** как на [strudel.cc](https://strudel.cc/):
   - `@strudel/core` — базовые функции
   - `@strudel/webaudio` — аудиосистема
   - `@strudel/soundfonts` — звуковые банки (с проблемой импорта)

2. **Правильная последовательность инициализации:**
   ```javascript
   // 1. Загрузить модули
   // 2. Экспортировать в window
   // 3. Инициализировать аудио
   // 4. Создать REPL instance через window.repl()
   // 5. Зарегистрировать soundfonts
   ```

3. **Правильный порядок воспроизведения:**
   ```javascript
   // НЕПРАВИЛЬНО:
   repl.start();
   repl.evaluate('s("bd")'); // ❌ Ошибка "no pattern set"
   
   // ПРАВИЛЬНО:
   await repl.evaluate('s("bd")'); // ✅ Сначала установить паттерн
   repl.start();                   // ✅ Потом запустить
   ```

4. **Обход проблемы с @strudel/soundfonts:**
   - Обнаружена проблема CommonJS/ESM (`DEFAULT_GENERATOR_VALUES`)
   - Решение: временно убрать импорт, использовать альтернативные методы регистрации звуков

## 🚨 Выявленные проблемы и решения

### Проблема 1: Импорт @strudel/soundfonts
**Ошибка:** `SyntaxError: The requested module does not provide an export named 'DEFAULT_GENERATOR_VALUES'`
**Причина:** Конфликт CommonJS/ESM в пакете soundfont2@0.4.0
**Решение:** Использовать `window.registerSoundfonts()` вместо прямого импорта

### Проблема 2: Порядок вызовов
**Ошибка:** `Scheduler: no pattern set! call.setPattern first`
**Причина:** Вызов start() до evaluate()
**Решение:** Строгий порядок: evaluate() → start()

### Проблема 3: Множественная загрузка
**Ошибка:** `@strudel/core was loaded more than once`
**Причина:** Двойной импорт в разных компонентах
**Решение:** Проверять наличие глобальных объектов перед импортом

```typescript
// 1. Убрать проблемный импорт
// БЫЛО: import('https://cdn.jsdelivr.net/npm/@strudel/soundfonts@latest/+esm')
// СТАЛО: // Пропускаем импорт, используем локальную регистрацию

// 2. Добавить локальную регистрацию звуков
const registerLocalSounds = async () => {
  try {
    // Загружаем только барабаны для начала
    const response = await fetch('/soundfonts/tidal-drum-machines.json');
    const drums = await response.json();
    
    // Регистрируем в soundMap
    if (window.soundMap && window.soundMap.setKey) {
      Object.entries(drums).forEach(([key, value]) => {
        window.soundMap.setKey(key, value);
      });
    }
  } catch (error) {
    console.warn('[UCH Strudel] Не удалось загрузить локальные звуки:', error);
  }
};

// 3. Вызывать после инициализации
await registerLocalSounds();
```

#### **Задача 2.1: Кэширование модулей**
```typescript
// Глобальный загрузчик модулей (синглтон)
class StrudelModuleLoader {
  private static instance: StrudelModuleLoader;
  private modules: Map<string, any> = new Map();
  
  static async getInstance() {
    if (!this.instance) {
      this.instance = new StrudelModuleLoader();
      await this.instance.loadAll();
    }
    return this.instance;
  }
  
  async loadAll() {
    const [core, webaudio] = await Promise.all([
      this.loadModule('core', 'https://cdn.jsdelivr.net/npm/@strudel/core@latest/+esm'),
      this.loadModule('webaudio', 'https://cdn.jsdelivr.net/npm/@strudel/webaudio@latest/+esm')
    ]);
    
    // Экспорт в window
    window.note = core.note;
    window.s = core.s;
    window.webaudioOutput = webaudio.webaudioOutput;
    window.repl = core.repl;
  }
  
  private async loadModule(name: string, url: string) {
    if (this.modules.has(name)) {
      return this.modules.get(name);
    }
    const module = await import(url);
    this.modules.set(name, module);
    return module;
  }
}
```
