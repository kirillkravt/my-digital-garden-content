## 🤖 **DeepSeek**

**Подтверждение:** Все 11 console.log содержат эмодзи и являются информативными. Согласно плану, мы должны оставить **только ключевые** логи. В плане указано: "оставляем только ключевые логи (по одному на компонент)", но для ноды StrudelREPL можно оставить логи основных действий: инициализация, запуск, остановка, очистка.

**Принято решение (в соответствии с best practice):** Удалить логи отладки, оставить логи основных жизненных циклов и ошибок. Удалим:
1. Строку 27 (использование глобального Strudel) — можно оставить, но не обязательно.
2. Строку 64 (предупреждение о AudioContext) — важно для отладки autoplay, оставим.
3. Строки 109 и 127 (подтверждения успеха) — можно объединить с основным действием или оставить.

Однако, чтобы следовать **поэтапному подходу** и не делать много изменений сразу, начнём с удаления явно отладочных логов без эмодзи (если они есть), но в нашем случае все логи имеют эмодзи.

**Альтернативный подход из плана:** Использовать `sed` для удаления всех console.log, кроме содержащих эмодзи. Но так как все наши логи содержат эмодзи, это ничего не удалит.

**Обновлённое решение:** Учитывая инди-подход ("инструмент для себя"), можно оставить все логи с эмодзи, так как они полезны для отладки. Но задача — "уменьшение console.log". Удалим те, которые дублируют информацию или менее важны.

Удалим:
- Строка 27: `"♻️ Strudel уже загружен глобально..."` — можно узнать по отсутствию загрузки CDN.
- Строка 109: `"✅ Воспроизведение запущено"` — дублирует действие строки 100.
- Строка 127: `"✅ Воспроизведение остановлено"` — дублирует действие строки 124.

Выполним удаление этих трёх строк.

### **Действие 37: Диагностика и решение проблемы загрузки семплов**

**Причина:** Strudel ожидает, что семплы уже загружены в AudioContext, но загрузка требует времени и, возможно, не завершается до первого использования.

**Решение:** Нужно явно загрузить банк семплов перед использованием, либо использовать встроенные семплы, которые гарантированно есть.

**Проверим, что говорит документация Strudel:** На [strudel.cc](https://strudel.cc/workshop/first-sounds/) используется `sound().bank()`, но, возможно, на их сервере предзагружены семплы, а при локальном использовании CDN нужно явно загружать.

**Альтернативное решение:** Использовать синтезированные звуки или гарантированно работающие семплы.

**Давайте попробуем:** 

1. **Явная загрузка банка** через `window.strudel?.loadSamples?.(bankName)` (если этот метод существует).

```typescript
// src/core/StrudelREPLNode.tsx
// Глобальный флаг загрузки Strudel для всей страницы
declare global {
  interface Window {
    __strudelLoaded?: boolean;
  }
}
import React, { useEffect, useRef, useState } from 'react';

interface StrudelREPLNodeProps {
  nodeId: string;
  // другие пропсы по необходимости
}

export const StrudelREPLNode: React.FC<StrudelREPLNodeProps> = ({ nodeId }) => {
  const [isPlaying, setIsPlaying] = useState(false);
  const [isInitialized, setIsInitialized] = useState(false);
  const [code, setCode] = useState('note("c4 e4 g4")');
  const [samplesLoaded, setSamplesLoaded] = useState<string>(''); // Загруженный банк
  const audioContextRef = useRef<AudioContext | null>(null);
  const strudelLoadedRef = useRef(false);

  // 1. ИНИЦИАЛИЗАЦИЯ STRUDEL (ТОЛЬКО ОДИН РАЗ)
  useEffect(() => {
    const initializeStrudel = async () => {
      
      // Глобальная проверка - если Strudel уже загружен на странице
      if (window.__strudelLoaded) {
        audioContextRef.current = window.strudel?.getAudioContext() || null;
        setIsInitialized(true);
        return;
      }
      
      // Локальная проверка для этого экземпляра компонента
      if (strudelLoadedRef.current) return;

      try {
        console.log('🔄 StrudelREPLNode: Начинаем инициализацию...');
        
        // Загружаем скрипт если еще не загружен
        if (!window.strudel) {
          await new Promise<void>((resolve, reject) => {
            const script = document.createElement('script');
            script.src = 'https://unpkg.com/@strudel/web@latest';
            script.onload = () => {
              if (window.initStrudel) {
                window.initStrudel();
                console.log('✅ Strudel загружен с CDN');
                resolve();
              }
            };
            script.onerror = reject;
            document.head.appendChild(script);
                window.__strudelLoaded = true;
          });
        }

        // Получаем AudioContext
        if (window.strudel) {
          audioContextRef.current = window.strudel.getAudioContext();
          
          // Начинаем в suspended состоянии (требование autoplay policy)
          if (audioContextRef.current?.state === 'running') {
            await audioContextRef.current.suspend();
            console.log('⚠️ AudioContext приостановлен (autoplay policy)');
          }
          
          strudelLoadedRef.current = true;
          
          setIsInitialized(true);
          
          console.log('🎉 StrudelREPLNode готов к использованию');
        }
      } catch (error) {
        console.error('❌ Ошибка инициализации Strudel:', error);
      }
    };

    initializeStrudel();

    // 2. ОЧИСТКА ПРИ РАЗМОНТИРОВАНИИ
    return () => {
      console.log('🧹 StrudelREPLNode: очистка...');
      if (audioContextRef.current?.state !== 'closed') {
        audioContextRef.current?.suspend().then(() => {
          audioContextRef.current?.close();
          console.log('✅ AudioContext закрыт');
        });
      }
    };
  }, []);

  // Функция загрузки семплов
  const loadSamples = async (bankName: string) => {
    if (!window.strudel?.loadSamples) {
      console.error('❌ Метод loadSamples не доступен в window.strudel');
      return;
    }
    
    try {
      console.log(`🔄 Загрузка семплов банка: ${bankName}...`);
      await window.strudel.loadSamples(bankName);
      setSamplesLoaded(bankName);
      console.log(`✅ Семплы ${bankName} загружены`);
    } catch (error) {
      console.error(`❌ Ошибка загрузки семплов ${bankName}:`, error);
    }
  };

  // 3. PLAY - ЕДИНСТВЕННЫЙ РАБОЧИЙ СПОСОБ
  const handlePlay = async () => {
    if (!window.strudel || !audioContextRef.current) {
      console.error('❌ Strudel не инициализирован');
      return;
    }

    try {
      console.log('▶️ Запуск воспроизведения...');
      
      // Активируем AudioContext (требование браузеров)
      await audioContextRef.current.resume();
      
      // Проигрываем код из редактора
      window.strudel.evaluate(code);
      
      setIsPlaying(true);
    } catch (error) {
      console.error('❌ Ошибка при запуске:', error);
      setIsPlaying(false);
    }
  };

  // 4. STOP - ТОЛЬКО ЧЕРЕЗ AudioContext.suspend()
  const handleStop = async () => {
    if (!audioContextRef.current) {
      console.error('❌ AudioContext не доступен');
      return;
    }

    try {
      console.log('⏹️ Остановка воспроизведения...');
      await audioContextRef.current.suspend();
      setIsPlaying(false);
    } catch (error) {
      console.error('❌ Ошибка при остановке:', error);
    }
  };

  // 5. ВЫВОД ИНТЕРФЕЙСА
  if (!isInitialized) {
    return (
      <div className="strudel-repl-node">
        <div className="p-4 border rounded">
          <p className="text-gray-600">Инициализация Strudel...</p>
          <button 
            onClick={() => window.location.reload()}
            className="mt-2 px-3 py-1 bg-blue-100 text-blue-700 rounded text-sm"
          >
            Перезагрузить если зависло
          </button>
        </div>
      </div>
    );
  }

  return (
    <div className="strudel-repl-node">
      <div className="p-4 border rounded space-y-4">
        <div>
          <h3 className="font-medium mb-2">Strudel REPL Node</h3>
          <p className="text-sm text-gray-600 mb-3">ID: {nodeId}</p>
        </div>

        <div className="space-y-3">
          <div className="flex space-x-2">
            <button
              onClick={handlePlay}
              disabled={isPlaying}
              className={`px-4 py-2 rounded ${
                isPlaying 
                  ? 'bg-gray-300 cursor-not-allowed' 
                  : 'bg-green-500 hover:bg-green-600 text-white'
              }`}
            >
              ▶ Play
            </button>
            
            <button
              onClick={handleStop}
              disabled={!isPlaying}
              className={`px-4 py-2 rounded ${
                !isPlaying 
                  ? 'bg-gray-300 cursor-not-allowed' 
                  : 'bg-red-500 hover:bg-red-600 text-white'
              }`}
            >
              ⏹ Stop
            </button>
          </div>

          {/* Редактор кода Strudel */}
          <div className="mt-4">
            <label className="block text-sm font-medium text-gray-700 mb-2">
              Код Strudel:
            </label>
            <textarea
              value={code}
              onChange={(e) => setCode(e.target.value)}
              rows={4}
              className="w-full font-mono text-sm p-3 border rounded bg-gray-50 focus:ring-2 focus:ring-blue-500 focus:border-blue-500"
              placeholder='Пример: s("bd hh sd cp").bank("RolandTR909")'
            />
            <p className="text-xs text-gray-500 mt-1">
              Можно использовать любые конструкции Strudel.
            </p>
          </div>

          {/* Кнопки загрузки семплов */}
          <div className="flex flex-wrap gap-2 mt-3">
            <button
              onClick={() => loadSamples('RolandTR909')}
              disabled={samplesLoaded === 'RolandTR909'}
              className="px-3 py-1 text-sm bg-blue-100 text-blue-700 rounded hover:bg-blue-200 disabled:opacity-50"
            >
              {samplesLoaded === 'RolandTR909' ? '✅ TR-909 загружены' : 'Загрузить TR-909'}
            </button>
            <button
              onClick={() => loadSamples('RolandTR808')}
              disabled={samplesLoaded === 'RolandTR808'}
              className="px-3 py-1 text-sm bg-purple-100 text-purple-700 rounded hover:bg-purple-200 disabled:opacity-50"
            >
              {samplesLoaded === 'RolandTR808' ? '✅ TR-808 загружены' : 'Загрузить TR-808'}
            </button>
            <button
              onClick={() => loadSamples('AkaiLinn')}
              disabled={samplesLoaded === 'AkaiLinn'}
              className="px-3 py-1 text-sm bg-green-100 text-green-700 rounded hover:bg-green-200 disabled:opacity-50"
            >
              {samplesLoaded === 'AkaiLinn' ? '✅ AkaiLinn загружены' : 'Загрузить AkaiLinn'}
            </button>
          </div>
          
          {samplesLoaded && (
            <p className="text-xs text-green-600">
              ✅ Загружен банк: {samplesLoaded}
            </p>
          )}

          <div className="text-sm">
            <p>Состояние: 
              <span className={`ml-2 px-2 py-1 rounded ${
                isPlaying ? 'bg-green-100 text-green-800' : 'bg-gray-100 text-gray-800'
              }`}>
                {isPlaying ? 'Играет' : 'Остановлено'}
              </span>
            </p>
            <p className="mt-1">AudioContext: 
              <span className="ml-2 font-mono">
                {audioContextRef.current?.state || 'не доступен'}
              </span>
            </p>
          </div>

          <div className="pt-3 border-t">
            <p className="text-xs text-gray-500">
              Использует <code>@strudel/web@latest</code><br/>
              Stop: <code>audioContext.suspend()</code>
            </p>
          </div>
        </div>
      </div>
    </div>
  );
};
```
