Fork by Prompt (ИИ как переводчик)Самый мощный механизм для тяжелых артефактов.Пользователь видит сложный 3D-шейдер и нажимает «Форкнуть». Ленивый форк (Lazy Fork)Для особо тяжелых артефактов (например, нейросеть с обученными весами) форк не создает копию всего артефакта.Модель хранения:Оригинал хранит веса модели (1GB) + код инференса.Форк хранит только дифф: измененные параметры (JSON размером 1KB) + ссылку на оригинал.При запуске система подгружает оригинальные веса и применяет изменения на лету.Это работает как Git LFS или Docker-слои.
