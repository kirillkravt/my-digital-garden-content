### Процесс изменения режима и проведения операции СБП

| № шага | Участник | Действие / Событие | Описание | Условие / Режим |
| :--- | :--- | :--- | :--- | :--- |
| **1.1** | Payer -> Core | Запрос на проверку возможности проведения операции СБП | Начало процесса. Запрос типа POST. | |
| **1.2** | ABS -> Core | Запрос на изменение режима (Kafka) | Запрос содержит: a) Список счетов, b) Остатки для операций СБП, c) Параметр режима ABS. | |
| **1.3** | Core -> Core | Обработка запроса | Перенаправление запроса в модуль BO. | |
| **1.4** | Core -> BO | Запрос на обновление счетов и остатков | | |
| **1.5** | BO --> Core | Ответ: HTTP код 2xx | Успешное обновление счетов и остатков. | Успешное обновление |
| **1.6** | BO --> Core | Ответ: HTTP код 4xx | Ошибка записи. Процесс завершается. | [Не успех записи] |
| **1.7** | Core -> ABS | Ответ: Невозможность авторизации (Kafka) | Уведомление ABS об ошибке. | [Не успех записи] |
| **1.8** | Core -> Core | Откидываем запрос в Кэш | Сохранение состояния режима в кэше Core. | |
| **1.9** | Payer -> Core | Запрос выполнения операции (PUT) | Запрос на непосредственное проведение платежа. | |
| **1.10** | Core -> Core | Проверка режима Core из Кэша | Определение текущего режима работы (Online/Offline). | |
| **1.11** | Core -> Core | Смена маршрута авторизации | Выбор алгоритма авторизации в зависимости от режима. | |
| **1.12** | Core -> ABS | Запрос авторизации платежа (Kafka) | Запрос на резервирование средств. | **Online** |
| **1.13** | ABS -> ABS | Авторизация (резервирование) | Проверка и уменьшение доступного остатка. | **Online** |
| **1.14** | ABS --> Core | Ответ. Подтверждение резервирования | | **Online** |
| **1.15** | Core -> BO | Запрос авторизации платежа (XP Clearing) | Запрос на резервирование средств. | **Offline** |
| **1.16** | BO -> BO | Авторизация (резервирование) | Проверка и уменьшение доступного остатка в BO. | **Offline** |
| **1.17** | BO --> Core | Ответ. Подтверждение резервирования | | **Offline** |
| **1.18** | Core -> API | Запрос выполнения операции с подтверждением резервирования (PUT) | | |
| **1.19** | API --> Core | Response PUT. Подтверждение | | |
| **1.20** | Core --> ABS | Подтверждение операции для проводки (Kafka) | Запрос на окончательное списание/зачисление. | **Online** |
| **1.21** | ABS -> ABS | Списание/зачисление средств | Проведение операции и отражение в бухгалтерии. | **Online** |
| **1.22** | ABS --> Core | Подтверждение о прочтении очереди | | **Online** |
| **1.23** | Core -> BO | Запрос на проведение операции (XP addOperStage WS) | Запрос на окончательное списание/зачисление. | **Offline** |
| **1.24** | BO -> BO | Списание/зачисление по СБП | Проведение операции в модуле BO. | **Offline** |
| **1.25** | BO --> Core | Подтверждение выполнения операции | | **Offline** |
| **1.26** | Core --> ABS | Подтверждение операции (Kafka) | Отправка операции в ABS для постановки в очередь. | **Offline** |
| **1.27** | ABS -> ABS | Накопление в очереди | Операция будет обработана при переходе в Online. | **Offline** |
| **1.28** | ABS --> Core | Подтверждение о прочтении очереди | | **Offline** |
| **1.29** | Core --> Payer | Response PUT. Подтверждение о выполнении операции | Конец процесса, клиент получает результат. | |
